# AI 蚊式噪声检测 (CNN-DM) — 汇报摘要

---

## Slide 1: 背景与方案

**问题：**
- 蚊式噪声 (Mosquito Noise) 是视频压缩常见的视觉伪影
- 现有检测方案依赖人工调参的规则阈值，不同场景需要反复适配
- 维护成本高，跨场景泛化能力有限

**方案：**
- 用轻量级 4 层 CNN 替代规则阈值，自动学习特征到 DM 的映射

> ⚠️ **难点：** 蚊式噪声在频域和空域特征与树枝、草地、树叶等复杂纹理高度相似，传统规则方案在这些场景下极易误检/漏检，正是 CNN 要解决的核心问题 — 通过数据驱动学习更鲁棒的判决边界。

- **16 个手工设计特征：**

| 类别 | 特征 | 物理含义 |
|------|------|---------|
| 方差 | mean_var / low_var_count / high_var_count | block 内亮度方差分布，区分平坦/纹理/噪声区域 |
| 边缘 | edge_strength / edge_orientation_conf | 水平和垂直边缘强度及方向一致性 |
| 二阶差分 | second_diff_max / second_diff_min_max | 像素突变强度，反映蚊式噪声的典型高频特性 |
| 振铃 (Ringing) | ringing_mean_max / min / min_max | 振铃效应的 7 维描述，mosquito noise 核心特征 |
| | row_ringing_max / mean | |
| | col_ringing_max / mean | |
| 行/列差分 | row_diff_max / col_diff_max | block 边界处的亮度跳变 |

- **网络架构：** 4 层全卷积网络，输入 16 通道 9x9 patch，输出 DM 概率

```
Input: (16ch, 9x9) ← 16个特征
  ↓ Conv2D(16→32, 3x3) + ReLU + Clip(0,3)     → 32ch, 7x7
  ↓ Conv2D(32→16, 3x3) + ReLU + Clip(0,3)     → 16ch, 5x5
  ↓ Conv2D(16→16, 3x3) + ReLU + Clip(0,3)     → 16ch, 3x3
  ↓ Conv2D(16→1, 3x3)                          → 1ch, 1x1
  ↓ Sigmoid
  Output: DM概率 (0~1)
```

  - 无 BatchNorm，无浮点除，所有中间结果截断到 [0,3]
  - **硬件资源估算：**

| 项目 | 数值 | 说明 |
|------|------|------|
| 模型参数 | 11,729 个 | Conv 权重 + bias |
| 模型体积 (fp32) | ~47 KB | 存储于 Flash |
| 模型体积 (int8) | ~12 KB | QAT 量化后 |
| 峰值特征图内存 | ~1.2 MB | 片内 SRAM |
| 4K@GS=16 单帧计算量 | ~400 M MACs | GS=8 的 1/4，算力节约 75% |
| 4K@30fps 所需算力 | ~12 GOPS | 主流低成本 NPU (1-4 TOPS) 轻松覆盖 |

> 4K 以上分辨率使用 **GS=16** 模式，grid 数量降为 GS=8 的 1/4，算力同步降 75%，300fps 以内单芯片 NPU 均可应对。
- 支持 **GS=8**（精细模式）和 **GS=16**（高效模式）两种配置

## Slide 2: 进展与效果

**已完成：**
- 训练框架搭建，支持 GS8/GS16 两种配置
- 端到端推理流程，输出 DM 概率图和去噪结果
- QAT 量化通路（NNI），模型压缩到 8-bit 无显著精度损失
- 特征整数化改造，去除浮点运算，适配硬件

**效果对比（10 张测试图，GS=8）：**

| 指标 | 规则方案 | CNN 方案 |
|------|---------|---------|
| 维护方式 | 反复调参 | 数据驱动 retrain |
| 跨场景适应性 | 低 | 高 |
| 部署成本 | — | ~6KB 参数，支持 int8 |
