# 算法整体流程

## 训练流程

```
┌──────────────────────────────────────────────────────────┐
│  Step 1: 数据准备                                         │
│  ┌─────────────┐    ┌──────────────────┐                  │
│  │ 原始视频帧    │ → │ 人工标注 DM 区域   │                  │
│  └─────────────┘    └──────────────────┘                  │
│                            ↓                              │
│  ┌─────────────┐    ┌──────────────────┐                  │
│  │ 特征提取     │ → │ CSV 特征文件       │ ← 16 维特征/block │
│  │ (离线工具)   │    │ (每 81 行为一个    │                  │
│  │             │    │  9x9 patch)       │                  │
│  └─────────────┘    └──────────────────┘                  │
├──────────────────────────────────────────────────────────┤
│  Step 2: 训练 (dm_cnn.py)                                 │
│  ┌─────────────────────────────────────────┐              │
│  │  MosquitoPatchDataset                     │             │
│  │  ① 读取 CSV → 归一化 16 特征到 [0,1]      │             │
│  │  ② 每 81 行 reshape 为 (16, 9, 9) tensor  │             │
│  │  ③ 标签: DM=1, 非 DM=0                  │              │
│  └──────────────┬──────────────────────────┘              │
│                 ↓                                        │
│  ┌─────────────────────────────────────────┐              │
│  │  4 层 CNN (MosquitoDenoiseCNN)           │             │
│  │  Input: (batch, 16ch, 9x9)              │             │
│  │    → Conv2D(16→32, k=3) + ReLU + Clip   │             │
│  │    → Conv2D(32→16, k=3) + ReLU + Clip   │             │
│  │    → Conv2D(16→16, k=3) + ReLU + Clip   │             │
│  │    → Conv2D(16→1, k=3)                  │             │
│  │    → Sigmoid → DM probability            │             │
│  │  损失: BCELoss                           │
│  │  优化器: AdamW + ReduceLROnPlateau       │              │
│  └─────────────────────────────────────────┘              │
│                 ↓                                        │
│  输出: model/mosquito_denoise_cnn_*.pth                   │
│        model/best_th_*.npy (最佳阈值)                      │
└──────────────────────────────────────────────────────────┘
```

## 推理流程 (predict_cnn.py)

```
输入: BMP 图片 (如 1920x1080)

  ① Y 通道提取
     RGB → Y = 0.299*R + 0.587*G + 0.114*B

  ② 像素级特征图 (feature_compute_reference.py)
     - var_map: 每个像素的局部方差
     - h_edge, v_edge: 水平和垂直边缘强度 (Sobel)

  ③ 分 Block 统计 — 按 GS×GS 划分网格
     4K 以上用 GS=16, 以下用 GS=8

     ┌─────┬─────┬─────┐
     │ B0  │ B1  │ ... │  每个 Block 统计 16 个特征:
     ├─────┼─────┼─────┤   方差(3) + 边缘(2) + 二阶差分(2)
     │ ... │     │     │   + 振铃(7) + 行/列差分(2) = 16
     └─────┴─────┴─────┘
           ↓
     特征图: (gh, gw, 16)   ← gh=H/GS, gw=W/GS

  ④ 特征归一化
     所有特征统一 clamp(0,255) 再 /255 → [0,1] 范围

  ⑤ 边缘 Padding (补 4 像素, edge mode)
     (gh, gw, 16) → (gh+8, gw+8, 16)
     → 保证 9x9 感受野覆盖到边缘 Block

  ⑥ 4 层 CNN 推理 (全图一次 forward)
     Input: (1, 16, gh, gw)
       → Conv1: (1, 32, gh, gw)
       → Conv2: (1, 16, gh, gw)
       → Conv3: (1, 16, gh, gw)
       → Conv4: (1, 1, gh, gw)
       → Sigmoid
     Output: DM 概率图 (gh, gw)

  ⑦ 后处理
     - 概率图 > DM_TH → 标记为 DM 区域
     - 双边滤波 (BilateralFilter) 去噪
     - 概率加权融合: out = filter * prob + original * (1-prob)

  ⑧ 输出
     - xxx_out.bmp: 去噪结果
     - xxx_cnn.bmp: DM 检测 overlay (红色高亮)
```

## 训练与推理的关键差异

| 阶段 | 特征归一化 | 标签 | Loss |
|------|-----------|------|------|
| 训练 | 逐特征归一化 (NORM_DIV) | 0/1 硬标签 + label smoothing | BCEWithLogitsLoss |
| 推理 | 统一 /255 归一化 | — | — |

> 训练时每个特征按各自除数归一化 (如 mean_var/1020, edge_strength/255)。
> 推理时特征已整数化到 [0,255]，直接 /255 归一化，便于硬件实现、无需存储每特征除数表。
